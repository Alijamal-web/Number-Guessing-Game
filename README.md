

# Number Guessing Game

## About the Project
Number Guessing Game is a simple interactive command-line game developed using Python. The computer randomly selects a secret number between 1 and 20, and the player has five attempts to guess it correctly. After each guess, the program provides a hint to help the player.

## Features
- Random number generation.
- Five attempts to guess the secret number.
- Helpful hints after each guess.
- Automatic win detection.
- Displays the correct number if the player runs out of attempts.

## Technologies Used
- Python
- Random module

## How to Run
1. Clone or download this repository.
2. Make sure Python is installed on your computer.
3. Open the project folder.
4. Run the following command:

`python main.py`

## How to Play
1. The computer chooses a random number between 1 and 20.
2. Enter your guess.
3. Follow the hints:
   - "My number is higher."
   - "My number is lower."
4. You have five attempts to guess correctly.
5. Guess the secret number to win!
